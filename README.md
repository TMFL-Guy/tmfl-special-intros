# TMFL Special Intros — Halloween Classic

A 35-second animated cinematic browser intro for the **Baltimore Ravens vs. Tennessee Titans Halloween Classic**.

## Get it running on GitHub Pages

1. In this repository select **Add file → Upload files**.
2. Upload the supplied Halloween Classic image and name it **`halloween-classic.png`** (case-sensitive) in the repository root, alongside `index.html`.
3. Commit the image to the `main` branch.
4. Open **Settings → Pages → Build and deployment → Deploy from a branch**.
5. Choose **main** and **/(root)**, then **Save**.
6. Open `https://tmfl-guy.github.io/tmfl-special-intros/` and press **Start Cinematic** to play.

## Features

- Cinematic poster background, moving camera, fog, lightning and animated text
- Clock chimes and synthesized thunder cues, enabled by clicking Start
- Ravens and Titans team reveals, matchup finale, and replay button
- Responsive desktop and mobile browser layout

## Important limits

This project is a **browser-based motion-graphics introduction**, not a fully rendered photoreal CGI movie or an MP4. It does not yet have voice narration or independent 3D character animation. The current intro adapts the supplied Halloween Classic poster as its backdrop. An actual voiced CGI MP4 requires a separate rendering pipeline and audio assets.
